# Lenientree Int – Cinema QR Ordering System

A full-stack cinema food ordering system that allows customers to scan a QR code at their seat, browse the theatre menu, place food orders, and track order status.

The project is being developed as part of a Full Stack + AI Development program, with the goal of building and deploying a production-ready MVP.
