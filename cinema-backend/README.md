# Cinema QR Ordering Backend

Backend API for a cinema QR-based food ordering system.

## Features

- QR code based seat identification
- Theatre and screen information
- Theatre-specific food menu
- Create food orders
- Order item management
- Server-side price calculation
- Order status tracking

## Tech Stack

- Node.js
- Express.js
- TypeScript
- Supabase / PostgreSQL
- Postman
